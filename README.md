## 骨架：三个世界、三种魔法
阿格里帕在 I.1–2 中给出的纲领：世界分三层——**元素世界、天界、理智世界**；每一上层统治下一层，其力经下一层流下。法师则沿同一阶梯反向上升：以**医学与自然哲学**捕获元素之力，依**占星与数学**连接天界之力，以**宗教圣礼仪式**借诸理智者之能加以巩固（I.1）。三卷正对应三层：

| 卷 | 世界 | 学科 | 主要内容 |
|---|---|---|---|
| 第一卷 | 元素世界 | **自然哲学 / 自然魔法** | 四元素、隐秘德能、世界之灵、同情与反感、行星属性、熏香、戒指、毒术、迷惑、占卜、灵魂激情与想象、言语与字母之力 |
| 第二卷 | 天界 | **数学（数、几何、音乐、天文）/ 天界魔法** | 数之神秘（1–12 及以上）、字母数值、魔方、几何图形、和谐与人体比例、天体观察、像与护符、字符、土占、世界灵魂 |
| 第三卷 | 理智世界 | **神学 / 仪式魔法（宗教）** | 宗教与迷信、神名与卡巴拉、天使与精灵学、守护神、人与灵魂、死后与死灵术、预言与狂热、梦与抽签、净化、献祭、祝圣 |

## 贯穿的十个核心观念
1. **宇宙是一张流注之网**：神 → 理智/天使 → 天球与星辰 → 世界之灵（第五元素）→ 元素与万物。万物之“隐秘德能”来自理念经世界灵魂与星光的注入（I.11–14）。
2. **同情与反感（sympathia/antipathia）**：万物按相似相吸、相反相拒；行星“签名”（signatura）使人能辨认物之所属（I.15–33）。
3. **魔法是对上下界的“配对成婚”**：法师不创造力，只是把下界之物的禀赋与上界之力按时机与比例相配，产生奇效（I.2、I.37–38）；真正的魔法工作必同时包含物理学、数学、神学三门（I.2）。
4. **数是事物的形式原理**：毕达哥拉斯—柏拉图—卡巴拉的数论；行星魔方把数、行星、灵与理智之名连在一起（II.1–22）。
5. **人是小宇宙、神的形象**：人身上有一切世界的部分，故能认识与统摄一切（II.27、III.36）。
6. **灵魂的力量**：想象与情感能改变自身与他人之身体；坚定的信/轻信是一切运作的条件（I.62–68、III.4–6、III.43）。
7. **言语与名字有力**：咒语、专名、字母、神名——其力最终“出于神的言语”（I.69–74、III.11、III.36）。
8. **精灵学**：天使与精灵分三类（超天、世间、服役）与九品；人有三重守护者；精灵可被吸引而不可被强迫（III.16–33）。
9. **宗教是魔法的完成**：没有宗教的魔法是迷信或邪术；最高的魔法是心智借爱望信与神合一，“一切魔法力量的形式在于站立而不倒的灵魂”（III.1–6、III.44）。
10. **基督教卡巴拉**：十塞菲拉、神名、72 天使与诸天对应；基督之后四字名的力量转入“耶稣”之名（III.10–13、III.25）。

## 两个版本的关系（一句话版）
1510 年初稿（W）是一位 24 岁学者在特里特米乌斯指导下对费奇诺式“自然—精灵魔法”的系统化；1533 年定本（K）保留骨架，却**重排章节**（世界灵魂移入第二卷、占卜移入第一卷），并**大量加入卡巴拉、数学、精灵学与民俗材料**，同时更强调信仰、教会与“耶稣之名”，结尾又加上“分散隐藏”的阅读提示——而同年出版的《论虚妄》则公开“翻悔”。如何同时理解这两本书，是阿格里帕研究的核心问题（见 00_导论）。
